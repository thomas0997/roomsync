    ABOUT

    One place for your class's deadlines

    RoomSync helps students share deadlines, files and approvals in one room.
    A student project from Holy Angel University.

    Shared rooms

    One room per class or group

    Join with an invite code and see the same board and calendar as everyone else. Deadlines stop living in five different group chats.

    BoardCalendarChat

    Approved deadlines

    Peers check each other

    A classmate adds a task and a room admin approves it before it shows for everyone, so the board stays something you can trust.

    ApproveRejectHistory

    Notes and files

    Share what the class needs

    Upload PDFs, Word docs and code files for the room. Every file is checked before it is stored and is only ever offered as a download.

    PDFDOCXCode

    How it works

    1. 1

      Create a room

      Start a room for your class and share the invite code. Classmates join with it.

    2. 2

      Add a deadline

      Anyone in the room can add an assignment, quiz or exam with a due date.

    3. 3

      Admin approves

      A room admin approves it, and it shows up for everyone on the board and calendar.
